# Nirapod Family Android downloads

These are development/debug builds, not a finished production release.

- [Download Parent APK](https://github.com/voirade-pw/nirapodfamily/raw/refs/heads/main/downloads/nirapod-family-parent-debug.apk)
- [Download Child APK](https://github.com/voirade-pw/nirapodfamily/raw/refs/heads/main/downloads/nirapod-family-child-debug.apk)

If GitHub opens a file page, use **Download raw file** to save the APK.

Both apps require a reachable HTTPS backend and device pairing for connected features. No backend has been publicly deployed. Some functionality remains incomplete or unverified on physical devices. These APKs were built on 2026-11-04; they are not Play Store releases.

Only APK download artifacts and this README are included in this upload. Application source remains in the development workspace.

## Version 0.2.0 — native interface redesign

The parent app now has Home, Family, Controls, Alerts and Account tabs. The child app has Home, Requests and Settings tabs. Includes a shared visual design, Bengali section headings, card-based controls, a prominent SOS action, clock-based downtime selection, loading feedback, readable report dialogs and a launcher icon. Existing API actions remain connected. Both APKs compile and their signatures verify. Visual verification in a fully booted emulator is still pending; this is not a claim of complete product readiness.

Install these over the previous debug versions to retain local settings. No backend has been publicly deployed.
